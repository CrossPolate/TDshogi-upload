# public/music/ — 已不再内置 BGM

**2026-10-21 起，代码仓库不再自带任何音乐文件。**

BGM 改为**管理员在后台「商城管理」上传**，再上架为商城商品：

1. 打开 `/admin.html` →「🛒 商城」；
2. 在「上传素材」里选 `BGM 音频`（mp3 / ogg / wav，≤12MB）并上传；
3. 在「新建 / 覆盖商品」里选择类型 `BGM`、场景（菜单 / 开局 / 终盘）、价格，保存；
4. 玩家在「个人页 → 我的装扮」购买/装备后生效。

如需设置**游客或未装备玩家的全局兜底曲**，在同一个「商城」页的
「BGM 三轨」里选择已上传的素材并保存；默认三轨全静音。

## 缺失时的行为

- 未上传 / 未装备 / 素材被删除 → **静音**；
- 不再自动合成 ambient pad（旧的合成兜底已移除）；
- 不会反复请求 404：服务端会校验站内素材是否存在，缺失的轨道自动回落为静音。

## 为什么不放仓库里

音乐文件体积大、授权来源需要逐首确认。把素材留在服务器上传目录
（`public/uploads/items/`，已在 `.gitignore` 中忽略）可以避免：
- 仓库 / 部署包体积膨胀；
- 未经确认的第三方音乐被公开分发；
- 代码仓库与运营素材耦合（换曲不必发版）。
